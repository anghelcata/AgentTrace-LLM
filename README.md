# AgentTrace-LLM

Minimal reproducibility package for the study:

**AgentTrace-LLM: Auditing Forensic Reconstruction of Causal Contamination in Multi-Agent LLM Systems**

This repository contains selected benchmark materials, forensic schemas, the forensic investigator specification, deterministic scoring code, and processed experimental results supporting the analyses reported in the manuscript.

Raw investigator outputs, intermediate execution artifacts, and internal orchestration files are not included.
